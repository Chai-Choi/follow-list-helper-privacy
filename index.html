中文

扩展在X页面读取当前登录账号的显示名称与用户名、目标账号、关注和申请状态，以及用户主动提供的名单。CSV/XLSX在本机解析，文件名、提取结果和输入草稿可能保存在Chrome本地存储。

用途为核对操作账号、执行用户主动开始的顺序自动关注、呈现页面结果、保存进度、手动重试、恢复和导出。成功仅代表页面当时显示已关注，不进行刷新二次核验。当前版本没有自动重试、失败后冷却续跑或防睡眠功能。

扩展没有开发者运营的数据接收服务器、广告或分析服务，不向开发者上传本地名单或历史，不出售这些数据。关注操作通过已登录的X页面直接发送给X，受其政策处理。因此不承诺“零数据传输”或“不涉及跨境”。扩展不主动读取密码、Cookie、登录令牌或私信，不要求在扩展中输入凭据。

本地保存账号归属、名单、草稿、文件提取结果、语言与间隔设置、执行结果、历史和最近3个恢复点。旧归档在导入/恢复新任务时最多保留最近5000条，更早记录会淘汰，请先导出。当前任务结果不截断；其他本地数据保留至清理或卸载。

可导出CSV结果、JSON任务备份和历史JSON（历史JSON仅供查阅，不能恢复任务）。暂停且无在途操作时，可单独清理旧归档，保留当前任务、草稿、设置与恢复点；清空本地数据则删除全部扩展存储。下载的文件不会随清理或卸载删除，应自行管理副本。

开发者是否属于特定法域的数据控制者、处理合法基础及适用权利，应结合发布主体、地区和实际用途确认，本草稿不预先断言GDPR/PIPL/CCPA全部适用或已合规。任何新增服务器、遥测或商业数据用途须先更新实现及披露。

仅在确认实际符合Chrome Web Store限制性使用要求后，发布者才应在后台作相应认证。数据不用于广告、转售或信用评估等无关用途。SheetJS CE本地打包并附开源许可证。

English

Publisher display name: ChaiChai_ChoiChoi (individual publisher based in Hong Kong; legal name to be confirmed). Support email: ashlej666@icloud.com. This policy is a draft; the effective date will be set before publication.

The extension reads the signed-in X account name/handle, target handles and follow/request states, and account lists supplied by the user. CSV/XLSX files are parsed locally; file names, extracted results and drafts may be saved in Chrome local storage.

Data supports account verification, user-started sequential automatic following, page-result display, progress, manual retry, recovery and export. Success means the page displayed Following, not a refreshed or server-confirmed result. There is no automatic retry, failure-count cooldown/resume or wake lock.

There is no developer-operated data collection server, advertising or analytics service. Lists/history are not uploaded to the developer or sold. Follow actions are sent directly to X through its signed-in page and processed under its policies. This is not a claim of zero transmission or no cross-border processing. The extension does not intentionally read passwords, cookies, authentication tokens or private messages, and does not ask for credentials.

Local storage retains task ownership, lists, drafts, extracted file results, language/settings, results, history and the latest three recovery points. Archived history is limited to the latest 5,000 entries when another task is imported or restored; export first. Current task results are not truncated. Other data remains until cleared or uninstalled.

Users can export result CSV, task backup JSON and reference-only history JSON. While paused with no operation in flight, archived history alone can be cleared without removing the current task, drafts, settings or recovery points. Clear local data removes all extension storage. Downloaded files and other copies must be deleted separately.

Applicable laws, controller status, legal bases and rights must be assessed against the actual publisher, territories and purposes. This draft does not assume blanket GDPR/PIPL/CCPA applicability or certify compliance. New server, telemetry or commercial data uses require updated implementation and disclosures. Limited Use certifications must only be made after verifying actual compliance. Data is not used for unrelated advertising, resale or creditworthiness. The bundled SheetJS CE license is retained.
